匯入題庫

題庫會存在這個瀏覽器中。設定「雲端同步」後，其他裝置同步一次就能取得。

支援 Gist 頁面、GitHub 檔案頁面與 Raw 連結。注意：拿到網址的人都能看到題庫內容。
    題庫格式說明

    可以直接匯入題目陣列，或加上科目資訊與共用圖片的完整格式：

    {
  "subject": { "id": "physiology-1", "name": "生理學", "subtitle": "一段" },
  "images": { "heart.png": "data:image/png;base64,…" },
  "questions": [
    {
      "id": "Q0001",
      "topic": "Cardiovascular",
      "stem": "題幹",
      "options": { "A": "選項 A", "B": "選項 B", "C": "選項 C", "D": "選項 D" },
      "answer": "B",
      "explanation": "詳解",
      "years": [112, 113],
      "image": "heart.png"
    }
  ]
}

    必填：stem（題幹）。有選項時需要 answer，多個正解寫成 "A/C"。圖片可寫在 images 裡讓多題共用，或直接用 https:// 圖片網址。為了安全，題目中的程式碼與外部連結會被移除，只保留粗體、上下標、換行等基本格式。
